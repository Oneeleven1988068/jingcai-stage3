# Live Final Freeze Policy

A live conclusion may be frozen only after:
1. Official Sporttery source integrity passes.
2. Source timestamps are shown per pool.
3. Stale/asynchronous pools are flagged.
4. External target coverage is audited.
5. Browser fallback is attempted when coverage fails and browser access exists.
6. Context evidence is labeled by source/state.
7. Final rating respects production/shadow boundary.
8. Freeze occurs before Sporttery sales cutoff.

Post-cutoff data cannot change the pre-sale frozen recommendation.
