# Confirmation Provenance Gate

Status: **SHADOW / GOVERNANCE AUDIT**  
Production baseline: **Jingcai 3.4 unchanged**

## Core rule

`HAD + HHAD + TTG + CRS + HAFU` from the same Sporttery source are not five independent pieces of evidence.

They may provide valuable **structural consistency**, but independent confirmation must be counted at the **source-family level**.

## Mandatory labels

Use:

- `SAME_SOURCE_STRUCTURAL_CONSISTENCY`
- `INDEPENDENT_CONFIRMATION`
- `EXTERNAL_PRICE_CONFIRM`
- `EXTERNAL_CONTEXT_CONFIRM`

Never turn multiple correlated pools from one source into an inflated independent-confirmation count.

## Example

Five Sporttery pools aligned to H plus one independent Pinnacle H2H direction:

- raw aligned observations = 6
- independent source families = 2

The correct statement is not “six confirmations.”

## No automatic action

This gate changes provenance accounting and confidence language only. It does not automatically change probabilities, ratings, staking, or model promotion.
